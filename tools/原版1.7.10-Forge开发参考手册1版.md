## 第 0 章 源码结构、混淆名与开发环境

### 0.1 你给的源码目录是什么

```
1.7.10-Forge_10.13.4.1614-OptiFine_E7.jar.src/
├── a.java ... zzz.java        混淆类（默认包）
├── net/minecraft/...          仅 Main、Realms、MinecraftServer 等少数保留名
├── assets/minecraft/...       原版资源
└── META-INF/
```

这是 **OptiFine 反编译出来的混淆源码**，不是 MCP 开发源码：

- `a.java` 可能是 `Block`、`Item` 或任意类；
- 方法参数名是 `p_149727_1_` 这类自动名；
- 没有 `net.minecraft.block.Block` 这种可读包名。

开发时不要直接照抄这个目录的类名，应该：

1. 用 ForgeGradle 的 MCP 反编译源（本手册依据的版本）；
2. 或在 IDE 里 attach `forgeSrc-1.7.10-10.13.4.1614-sources.jar`；
3. 用 MCP 名写代码，发布时 ForgeGradle 会自动 reobf。

### 0.2 两套名字

| 场景 | 名字 |
|---|---|
| 写代码 | MCP 名：`Block`、`Item`、`World`、`getBlockHardness` |
| 发布到生产 | SRG 名：`func_149712_f` 等 |
| 混淆源 | `a`、`b`、`c` |
| 存档/资源 | 注册名：`minecraft:stone` |

ForgeGradle 的 `reobf` 负责 MCP→SRG；不要手写 SRG 名。

### 0.3 开发环境清单

- JDK 8（1.7.10 必须 Java 8）
- Forge 1.7.10-10.13.4.1614
- Gradle 4.10.x（ForgeGradle 1.2）
- IDE（IDEA/Eclipse）导入 Gradle 工程

`build.gradle` 关键：


## 第 1 章 Forge 模组生命周期与注册

### 1.1 主类

```java
@Mod(
    modid = "examplemod",
    name = "Example Mod",
    version = "1.0.0",
    dependencies = "required-after:Forge@[10.13.4.1614,)"
)
public class ExampleMod {

    public static final String MODID = "examplemod";
    public static final Logger LOG = LogManager.getLogger("ExampleMod");

    @Instance(MODID)
    public static ExampleMod instance;

    @SidedProxy(
        clientSide = "com.example.client.ClientProxy",
        serverSide = "com.example.CommonProxy"
    )
    public static CommonProxy proxy;

    @EventHandler
    public void preInit(FMLPreInitializationEvent event) {
        proxy.preInit(event);
        ModItems.init();
        ModBlocks.init();
        ModFluids.init();
        ModConfig.init(event.getModConfigurationDirectory());
    }

    @EventHandler
    public void init(FMLInitializationEvent event) {
        proxy.init(event);
        ModRecipes.init();
        ModEntities.init();
        ModGuiHandler.init();
    }

    @EventHandler
    public void postInit(FMLPostInitializationEvent event) {
        proxy.postInit(event);
    }
}
```

### 1.2 三个阶段能做什么

| 阶段 | 能做 | 不能做 |
|---|---|---|
| preInit | 注册物品/方块/流体/实体/矿词/配置/网络通道 | 读其他模组的最终配方 |
| init | 注册配方、GUI、事件、TileEntity、渲染 | 注册新物品/方块 |
| postInit | 兼容其他模组、注册依赖其他模组的配方 | 注册基础内容 |

### 1.3 注册物品

```java
public static Item example_item;

example_item = new Item();
example_item.setUnlocalizedName("example_item");
example_item.setTextureName("examplemod:example_item");
example_item.setCreativeTab(CreativeTabs.tabMaterials);
GameRegistry.registerItem(example_item, "example_item");
```

- 注册名：`examplemod:example_item`（1.7.10 不带 `item.` 前缀，除非自己加）；
- 语言键：`item.example_item.name`；
- 贴图：`assets/examplemod/textures/items/example_item.png`。

```java
example_block.setBlockTextureName("examplemod:example_block");
```

### 1.5 代理

```java
    public void init(FMLInitializationEvent e) {}
    public void postInit(FMLPostInitializationEvent e) {}
```

- `FMLCommonHandler.instance().bus()`：FML 事件（tick、服务器、配置）。

```java

```

### 1.7 配置文件

```java

cfg.load();

cfg.save();
```

### 1.8 常见注册错误

| 错误 | 原因 |
|---|---|
| 物品 ID 冲突 | 1.7.10 用名字注册，不会冲突；但 `setUnlocalizedName` 重复会覆盖语言 |
| 贴图紫黑 | 路径/尺寸不对，或没重新构建 |
| 服务端崩溃 `NoClassDefFoundError: net/minecraft/client` | 客户端类写进公共代码 |
| 方块没有掉落 | 没写 `getItemDropped` / `damageDropped` |
| TileEntity 不保存 | 没写 `writeToNBT/readFromNBT` |

### 2.3 碰撞箱与选中箱

```java
this.setBlockBounds(0.0F, 0.0F, 0.0F, 1.0F, 1.0F, 1.0F); // 只对普通方块有效
```

- `setBlockBounds` 设置的是**完整方块坐标内的局部范围**；
- 台阶/栅栏/箱子等动态形状要重写：

```java
@Override
public void setBlockBoundsBasedOnState(IBlockAccess world, int x, int y, int z) {
    this.setBlockBounds(0.0F, 0.0F, 0.0F, 1.0F, 0.5F, 1.0F);
}

@Override
public AxisAlignedBB getCollisionBoundingBoxFromPool(World world, int x, int y, int z) {
    return AxisAlignedBB.getBoundingBox(x, y, z, x + 1, y + 0.5, z + 1);
}
```

- `getSelectedBoundingBoxFromPool` 是准星选中箱；
- `addCollisionBoxesToList` 用于多碰撞箱（楼梯、栅栏）；
- `isOpaqueCube` 决定是否完整不透明；
- `renderAsNormalBlock` 决定是否用标准渲染；
- `getRenderType` 返回自定义渲染器 ID（`-1` 表示用 TESR）。

### 2.4 硬度、爆炸抗性、采集

- `setHardness(0.5F)`：泥土；`50F`：黑曜石；`-1F`：不可破坏；
- `setResistance(15F)`：爆炸抗性；黑曜石 1200；
- 采集等级用 Forge 工具系统：

```java
this.setHarvestLevel("pickaxe", 2); // 需要铁镐及以上
```

原版工具等级：

| 工具 | 等级 |
|---|---|
| 木/金 | 0 |
| 石 | 1 |
| 铁 | 2 |
| 钻石 | 3 |

硬度的实际破坏时间（ForgeHooks）：

```
能采集：时间 = 玩家挖掘速度 / 硬度 / 30
不能采集：时间 = 玩家挖掘速度 / 硬度 / 100
```

### 2.5 掉落物

默认：`getItemDropped` 返回 `Item.getItemFromBlock(this)`，数量 1，meta = `damageDropped`。

```java
@Override
public Item getItemDropped(int meta, Random rand, int fortune) {
    return Items.diamond;
}

@Override
public int quantityDropped(Random rand) {
    return 1 + rand.nextInt(3);
}

@Override
public int quantityDroppedWithBonus(int fortune, Random rand) {
    return this.quantityDropped(rand) + rand.nextInt(fortune + 1);
}

@Override
public int damageDropped(int meta) {
    return meta; // 保留 meta
}
```

精准采集：默认 `canSilkHarvest()` 返回 true 且 `createStackedBlock` 复制方块；
要禁用：`@Override protected boolean canSilkHarvest() { return false; }`。

自定义掉落列表（Forge）：

```java
@Override
public ArrayList<ItemStack> getDrops(World world, int x, int y, int z, int metadata, int fortune) {
    ArrayList<ItemStack> drops = new ArrayList<ItemStack>();
    drops.add(new ItemStack(Items.diamond, 1));
    return drops;
}
```

### 2.12 方块实体刻

```java
public class TileMachine extends TileEntity {
    public int progress;

    @Override
    public void updateEntity() {
        if(worldObj == null || worldObj.isRemote) return;
        progress++;
        if(progress >= 100) { progress = 0; doWork(); }
    }

    @Override
    public void writeToNBT(NBTTagCompound nbt) {
        super.writeToNBT(nbt);
        nbt.setInteger("progress", progress);
    }

    @Override
    public void readFromNBT(NBTTagCompound nbt) {
        super.readFromNBT(nbt);
        progress = nbt.getInteger("progress");
    }
}
```

- TE 每 tick 调用 `updateEntity`；
- 只有被加载的区块才 tick；
- 需要同步时用 `markDirty()` + 自定义包/DataWatcher。

## 第 18 章 性能、调试与常见坑

### 18.1 性能

- 不要每 tick 遍历全世界上万方块；
- 用 `world.scheduleBlockUpdate` 而不是每 tick 检查；
- 缓存 `getTileEntity`；
- 避免频繁 `new ItemStack`；
- 客户端渲染不要做服务端逻辑；
- 大网络包拆分。

### 18.2 常见坑

| 问题 | 解决 |
|---|---|---|
| 服务端崩溃 `net.minecraft.client` | 客户端代码放 ClientProxy |

| GUI 打不开 | GUI Handler ID/服务端返回 null |

```java
public class BlockMachineExample extends BlockContainer {
```

### G.4 TileEntity

```java
public class TileMachineExample extends TileEntity implements IInventory {
    private ItemStack[] slots = new ItemStack[2];
    public int power;
    public int progress;
    public static final int MAX_POWER = 10000;

    @Override
    public void updateEntity() {
        if(worldObj == null || worldObj.isRemote) return;
        if(slots[0] == null || slots[1] != null) return;

        if(power > 0) {
            power--;
            progress++;
            if(progress >= 100) {
                progress = 0;
                slots[1] = slots[0].copy();
                slots[0] = null;
                markDirty();
            }
        }
    }

    @Override public int getSizeInventory() { return slots.length; }
    @Override public ItemStack getStackInSlot(int i) { return slots[i]; }
    @Override public ItemStack decrStackSize(int i, int n) {
        if(slots[i] == null) return null;
        ItemStack out;
        if(slots[i].stackSize <= n) { out = slots[i]; slots[i] = null; }
        else { out = slots[i].splitStack(n); if(slots[i].stackSize <= 0) slots[i] = null; }
        markDirty();
        return out;
    }
    @Override public ItemStack getStackInSlotOnClosing(int i) { return slots[i]; }
    @Override public void setInventorySlotContents(int i, ItemStack s) { slots[i] = s; markDirty(); }
    @Override public String getInventoryName() { return "container.machine_example"; }
    @Override public boolean hasCustomInventoryName() { return false; }
    @Override public int getInventoryStackLimit() { return 64; }
    @Override public boolean isUseableByPlayer(EntityPlayer p) {
        return worldObj.getTileEntity(xCoord, yCoord, zCoord) == this
                && p.getDistanceSq(xCoord + 0.5, yCoord + 0.5, zCoord + 0.5) <= 64;
    }
    @Override public void openInventory() { }
    @Override public void closeInventory() { }
    @Override public boolean isItemValidForSlot(int i, ItemStack s) { return i == 0; }

    @Override public void writeToNBT(NBTTagCompound nbt) {
        super.writeToNBT(nbt);
        nbt.setInteger("power", power);
        nbt.setInteger("progress", progress);
        NBTTagList list = new NBTTagList();
        for(int i = 0; i < slots.length; i++) if(slots[i] != null) {
            NBTTagCompound tag = new NBTTagCompound();
            tag.setByte("slot", (byte) i);
            slots[i].writeToNBT(tag);
            list.appendTag(tag);
        }
        nbt.setTag("items", list);
    }

    @Override public void readFromNBT(NBTTagCompound nbt) {
        super.readFromNBT(nbt);
        power = nbt.getInteger("power");
        progress = nbt.getInteger("progress");
        slots = new ItemStack[2];
        NBTTagList list = nbt.getTagList("items", 10);
        for(int i = 0; i < list.tagCount(); i++) {
            NBTTagCompound tag = list.getCompoundTagAt(i);
            int slot = tag.getByte("slot") & 255;
            if(slot < slots.length) slots[slot] = ItemStack.loadItemStackFromNBT(tag);
        }
    }
}
```

## 附录 H 原版机制细节补充

### H.1 附魔台

- 书架必须放在附魔台周围 2 格内、同一层或高 1 格；
- 每个书架提供 2 点“附魔力量”，上限 15 个书架（30 点）；
- 三个选项的等级：

```
基础 = 1 + rand(8) + floor(bookshelves / 2) + rand(bookshelves + 1)
选项 1 = max(基础 / 3, 1)
选项 2 = 基础 * 2 / 3 + 1
选项 3 = max(基础, bookshelves * 2)
```

- 消耗青金石：选项 1/2/3 分别 1/2/3 个；
- 消耗等级：选项等级。

### H.2 铁砧

- 修复：材料修复（每个材料修 25% 耐久）或同物品合并（耐久相加 + 12%）；

- 累计惩罚：每次使用增加 1 级，超过 40 级过于昂贵。

## 附录 Q 逐行注释模板与坑

### Q.1 方块：每一行在做什么

```java
public class BlockExample extends Block {

    public BlockExample() {
        // 材质决定：能否被工具采集、是否可燃、声音/粒子默认值、地图颜色
        super(Material.rock);

        // 语言键 = tile.<name>.name；不要带 modid
        this.setBlockName("example_block");

        // 贴图 = assets/<modid>/textures/blocks/<path>.png
        this.setBlockTextureName("examplemod:example_block");

        // 硬度：0.5 泥土、1.5 石头、3 铁块、50 黑曜石、-1 不可破坏
        this.setHardness(3.0F);

        // 爆炸抗性：石头 10、铁块 30、黑曜石 1200
        this.setResistance(15.0F);

        // 音效：stone/wood/gravel/grass/metal/glass/cloth/sand/snow/ladder/anvil
        this.setStepSound(Block.soundTypeStone);

        // 亮度 0~1；1.0 = 15 级光
        this.setLightLevel(0.0F);

        // 遮光 0~255；0 = 完全透光，255 = 完全不透光
        this.setLightOpacity(255);

        // 是否接收随机刻（作物/草/冰需要）
        this.setTickRandomly(false);

        // 创造模式物品栏
        this.setCreativeTab(CreativeTabs.tabBlock);
    }

    // 玩家右键：返回 true 表示“已处理”，不再调用物品的 onItemUse
    @Override
    public boolean onBlockActivated(World world, int x, int y, int z,
            EntityPlayer player, int side, float hitX, float hitY, float hitZ) {
        // 只在服务端打开 GUI，客户端只返回 true
        if(!world.isRemote) player.openGui(ExampleMod.instance, 0, world, x, y, z);
        return true;
    }

    // 被破坏时：默认掉落本方块；需要自定义就重写 getDrops
    @Override
    public ArrayList<ItemStack> getDrops(World world, int x, int y, int z, int meta, int fortune) {
        ArrayList<ItemStack> drops = new ArrayList<ItemStack>();
        // fortune 是时运等级；0 表示没有
        drops.add(new ItemStack(this, 1, meta));
        return drops;
    }
}
```

坑：

- `setBlockBounds` 只对普通方块生效；动态形状要重写 `setBlockBoundsBasedOnState`；
- 方块是单例，不要在构造里保存坐标；
- `onBlockActivated` 客户端也会调用，GUI 只在服务端打开；
- 不要漏 `getItemDropped`/`damageDropped`，否则 meta 丢失；
- 带 TE 的方块必须用 `BlockContainer` 或重写 `hasTileEntity`。

```java
    @Override
```

### Q.3 机器：TE + Container + GUI 的注释版

```java
public class TileMachine extends TileEntity implements IInventory {

    // 槽位数组：0 输入、1 输出
    private ItemStack[] slots = new ItemStack[2];

    // 能量/进度：必须写进 NBT，否则重进世界丢失
    public int power;
    public int progress;

    @Override
    public void updateEntity() {
        // 客户端不跑逻辑；TE 在客户端也会 tick
        if(worldObj == null || worldObj.isRemote) return;

        // 每 tick 逻辑：耗电、推进、产出
        if(power > 0) {
            power--;
            progress++;
            if(progress >= 100) {
                progress = 0;
                slots[1] = slots[0] == null ? null : slots[0].copy();
                slots[0] = null;
                // 标记脏数据，让区块保存
                markDirty();
            }
        }
    }

    @Override
    public void writeToNBT(NBTTagCompound nbt) {
        super.writeToNBT(nbt);
        nbt.setInteger("power", power);
        nbt.setInteger("progress", progress);

        // 物品栏必须逐个写；不能直接 setTag(ItemStack)
        NBTTagList list = new NBTTagList();
        for(int i = 0; i < slots.length; i++) {
            if(slots[i] == null) continue;
            NBTTagCompound tag = new NBTTagCompound();
            tag.setByte("slot", (byte) i);
            slots[i].writeToNBT(tag);
            list.appendTag(tag);
        }
        nbt.setTag("items", list);
    }

    @Override
    public void readFromNBT(NBTTagCompound nbt) {
        super.readFromNBT(nbt);
        power = nbt.getInteger("power");
        progress = nbt.getInteger("progress");

        slots = new ItemStack[2];
        NBTTagList list = nbt.getTagList("items", 10); // 10 = COMPOUND
        for(int i = 0; i < list.tagCount(); i++) {
            NBTTagCompound tag = list.getCompoundTagAt(i);
            int slot = tag.getByte("slot") & 255;
            if(slot < slots.length) slots[slot] = ItemStack.loadItemStackFromNBT(tag);
        }
    }
}
```

坑：

- `readFromNBT` 里要先 `new ItemStack[长度]`，否则空指针；
- `getTagList("items", 10)` 第二个参数是类型，写 10（COMPOUND）；
- TE 的 `updateEntity` 客户端也执行，逻辑必须判 `worldObj.isRemote`；
- 容器槽位 `Slot` 的坐标是 GUI 内坐标，不是屏幕坐标；
- GUI 只在客户端创建，Container 只在服务端创建；
- 打开 GUI 时服务端要校验距离/权限，否则可远程打开。

### Q.4 常见坑总表

| # | 坑 | 后果 | 正确做法 |
|---|---|---|---|---|
| 1 | 在客户端跑机器逻辑 | 不同步/刷物品 | `if(world.isRemote) return;` |
| 2 | 服务端加载 `net.minecraft.client` | 专用服务器崩溃 | 放 ClientProxy/ `@SideOnly` |
| 3 | 注册顺序错 | 物品/方块为 null | 物品/方块 preInit，配方 init/postInit |
| 4 | 配方不挂监听 | `/ntmreload` 后消失 | `SerializableRecipe.additionalListeners` |
| 5 | TE 没写 NBT | 重进世界丢失 | write/read NBT |
| 6 | 方块没 `damageDropped` | meta 丢失 | 重写并返回 meta |
| 7 | 工具没 `setHarvestLevel` | 挖不动高等级方块 | 设置 tool class/level |
| 8 | GUI 坐标算错 | 槽位错位 | 用 `guiLeft/guiTop` 相对坐标 |
| 9 | 客户端改方块 | 回弹/不同步 | 服务端 `setBlock` |
| 10 | 每 tick 遍历大范围 | 卡顿 | 用计划刻/缓存 |
| 11 | 事件没取消 | 原版逻辑继续 | `event.setCanceled(true)` |
| 12 | `ItemStack` 为 null 未判 | NPE | 先判空 |
| 13 | 直接改 `stack.stackSize` 负数 | 刷物品 | 用 `splitStack/decrStackSize` |
| 14 | 维度 ID 冲突 | 传送崩溃 | 用未占用 ID |
| 15 | 实体没注册渲染 | 隐身/崩溃 | ClientProxy 注册 |
| 16 | 网络包在错误线程处理 | 并发问题 | 回主线程 `addScheduledTask` |
| 17 | 流体单位当桶 | 1000 倍错误 | 1 桶 = 1000 mB |
| 18 | 附魔/药水 ID 冲突 | 覆盖原版 | 用空闲 ID/注册名 |
| 19 | 方块材质/音效没设 | 手感怪 | 参照原版方块 |
| 20 | 贴图路径大小写 | 紫黑格 | 全小写、路径一致 |
